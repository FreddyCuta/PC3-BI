# Evidencias

Toda cifra o afirmación del informe debe tener evidencia localizable aquí.

## Estructura

- `relevo/`: validaciones de recepción Fase 2.
- `P1..P8/`: consultas, resultados, capturas, RunId por caso e intento.
- `kpis/`: ejecuciones de KPI y conciliaciones.
- `modelo/`: diagrama, capturas de esquema/modelo.
- `costos/`: presupuesto, Cost Management, exportes.
- `seguridad/`: pruebas permitidas/denegadas.

## Reglas

- No sobrescribir intentos fallidos.
- Ocultar secretos, IPs sensibles y credenciales en capturas.
- Nombrar archivos con prueba/caso/lote/intento/fecha. Ej.: `P8_tobotex_L3_int2_runid-<id>.png`.
