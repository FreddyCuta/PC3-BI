# Checklist de entrega final

## Paquete

- [ ] PDF final del informe en `entregables/`.
- [ ] Scripts SQL y orden de ejecución (`sql/`, `sql/control/`).
- [ ] Contratos y datos/manifiestos (`contratos/`, `datos/`).
- [ ] Pipeline ADF exportado (`adf/`).
- [ ] Tablero Power BI y exportación (`powerbi/`).
- [ ] Bitácora y evidencias P1–P8 (`pruebas/`, `evidencias/`).
- [ ] Anexo E con cálculo independiente (`informe/anexo_e.md`, `anexo_e/`).
- [ ] README reproducible sin secretos.
- [ ] Demo ≤ 8 min con P3, P4, P6, P8 (`demo/`).

## Calidad

- [ ] Ninguna afirmación "ejecutado" sin evidencia.
- [ ] Cortes, fechas, unidades y cifras consistentes.
- [ ] Capturas sin secretos/IP/credenciales.
- [ ] Referencias APA 7 verificadas.
- [ ] Recursos Azure inventariados/eliminados tras entrega.
