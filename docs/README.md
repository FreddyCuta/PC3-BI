- `arquitectura.md`: Diseño A/B, diagrama, identidades.
- `reglas_calidad_publicacion.md`: C1–C8, conciliación, cortes, recuperación.
- `pruebas.md`: plan P1–P8 y criterios de pase.
- `seguridad_costos.md`: accesos, costos y consultas equivalentes.
