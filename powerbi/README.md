# Power BI

- `tobotex_pc3.pbix`: tablero principal (cuando se reciba/construya).
- `exportaciones/`: PDF de páginas, capturas con filtros/corte visible.

## Requisitos

- Conectar con usuario `bi_reader` (no `sqladmin`).
- Usar vistas `bi.*`.
- Mostrar corte publicado, fecha/hora de publicación y períodos revisados.
- Para P6, capturas deben mostrar filtro, corte y KPI conciliado.
